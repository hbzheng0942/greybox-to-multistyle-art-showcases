# A01 渲染与视觉特征方案

2026-10-27 · H2 设计草案。采用 `greybox-to-multistyle-art 0.9.0-alpha.1` 的 visual-feature-analysis／scene-effects 方法。目标是充气巡回博物馆；本文件没有修改场景、提交模型或宣称最终美术通过。

依据：已实际查看的最终七张 [目标图集](../atlas/)（原历史 atlas-review；本包哈希见 `process/catalog.json`），以及当前原生探针的中庭结构、玩法中庭、西门、标本馆、儿童区、门厅、东门、全倒塌 **8 张实际截图**。原生接口仍由 [空间设计](spatial-design.md) 与 native-facts 控制。

## 目标特征与实现归属

| 目标位置 → 可见要求 | 实现归属与容易误用的替代 | 原生验证 |
|---|---|---|
| V0／V1 猛犸：丰满气囊腿、厚胸腹肋壳、大头骨与长弯象牙；连续圆润轮廓，关节有深色领口 | **模型主形＋局部材质**。12个挂载组内设计体量、头牙和接合面；不能用细圆管代理加白色材质代替，也不能把整具合并为不可拆模型 | 原玩法机位先看完整侧影，再看部分拆落、全倒塌、咬住／甩出／R恢复；检查关节断口与身体跟随，不仅比完整态漂亮程度 |
| V0／V2／V5／V6 门套、柱梁、台裙：气囊鼓腹、端部压扁、束带勒缩和接头；V5横楣明显扁薄 | **受控接口＋外壳模型**。轮廓变化由几何承担；保持平顶和门内缘，气柱向实墙侧鼓起。均匀圆柱／圆角方盒只作占位 | 固定原生机位检查完整构图及四门正反侧；门厅横楣仍位于y3.60–3.80，主台顶y0.85。不得通过移动碰撞或抬高骨架迁就壳体 |
| V0–V6 布面：焊缝、包边、绑带、局部张力褶皱；有大块平静布面，织纹不是主图案 | **中尺度褶皱几何或法线＋低对比纹理；扣件／领口必要几何**。接缝是局部构造边，非全物体黑描边；不能把程序正弦细线当作完整织物结构 | 静止与移动镜头分别看近门套、远墙、骨关节；缝线位置要服从装配，远处不能变成闪烁条纹。删除细纹后仍应读出充气形体 |
| 全场奶油／深蓝／橙色：墙面分区和橙色入口引导；象牙白骨架与奶油台面仍有明度层次 | **分区纹理／材质＋统一灯光**。颜色沿实际面板和资产UV组织，避免一条世界高度色带切过所有柱／家具；不靠增亮曝光把白骨与白台融成一片 | 同一灯光下核对骨架、台面、墙面和犬；查看纹理颜色解释、法线与材质后再调灯。狗及可咬小件在蓝墙和浅地面前均可辨 |
| V2瓷器、V3／V6化石、织物家具：硬质小件有独立轮廓和克制亮边；布面宽柔高光，地面有弱反射而非镜面 | **按物类区分材质响应**。布料、釉面、化石、金属扣件分别设颜色与粗糙度，普通不透明材料优先；不能全场一套奶油高粗糙度材质 | 西门玩法机位与最近可咬物近景观察硬／软区别；甩出转动时高光连续，不因粗糙度或色彩解码错误误读材质。图中饰座不能抬高原生支撑 |
| V0／V1／V5：柔暖顶光和局部展灯，脚底、台裙与小件有接触影；背景可读而非泛白 | **已有灯具／环境＋普通动态阴影**。先复用当前灯位，按房间分配亮暗；保留动态骨段、犬与游客的落地影。不可用永久画在地上的黑斑冒充会移动对象的接触，也不能靠阴影遮掩悬空 | 固定曝光比较完整与倒塌；检查四脚与台面的实际接触、阴影偏移、狗移动和转角的阴影稳定性。静态缝隙可有材质内遮蔽，不能把永久光照烘在可移动道具上 |
| V0–V6狗／游客：四足布面犬、背带、短粗易读的游客；V4儿童身份与成人不同 | **角色模型／纹理＋原生运动生命周期**。四足外观围绕既有胶囊与嘴锚点装配；游客继续三段刚体及恢复。均一成年人代理和四根直腿不能代替身份与动作设计 | 普通追随镜头、咬物、跑动、碰倒游客与起身时检查脚底、嘴部、背带及分段接合；使用A01已验证儿童点位，不将角色藏入桌内 |
| V3／V6熊、鹿、狼：物种体态明确，局部绒面和缝合感属于同一展馆；远墙鱼骨／弯肋骨／叶片有浅浮雕 | **标本主形＋表面纹理／局部法线，牌面图文＋浅浮雕几何**。先解决熊肩背、鹿角长腿、狼口鼻耳尾，再做绒毛；当前圆角方块不足。无需把每根毛做成透明片或逐根几何 | 标本馆全景与东门都能辨物种；同一组墙牌内容、顺序和挂件统一。动物／牌面装配服从原生变换，静态大标本与可咬小边几物件明确分开 |

以上由可见特征确定责任，具体纹理、模型资产ID及供应商路线留在后续生产方案绑定；这里不虚构已经存在的资源。概念图没有证明真实充气、布料摆动或毛发运动，本阶段不新增布料模拟、呼吸变形或毛发系统。

## Compatibility 路线

当前 `project.godot` 的桌面与移动方法均为 `gl_compatibility`，保持不变。复用现有不透明材质、空间shader和原生灯光／阴影；图案采用贴图或实际表面牌面。墙面 shader 当前只有世界高度色带、低幅织纹与程序细线，它可作底色代理，不等于目标缝线与褶皱已实现。

当前探针材质 roughness=0.91、specular=0.15，墙材 roughness=0.95、specular=0.12；环境能量0.53并使用 Filmic，另有中庭接触用 SpotLight。上述是现状，**不是最终统一参数**。调试顺序为材质输入与法线 → 主形与接触 → 材质响应 → 局部灯光；不从一次全场加亮开始。

目标不需要依赖屏幕空间反射、体积雾、Bloom、描边后处理或新的全局光照系统。优先用已有漫射环境、受控局部光和动态阴影完成层次；仅在实际视图显示重要缺口时，才在同一探针隔离最小问题。大面积透明罩、厚雾和高反差地面条影会削弱交互读形，不纳入本方案。

## 当前差距与下一轮检查

当前代理已表达房间、门、台与12段运动关系，但实图仍有：猛犸腿／肋偏细、头牙泛化和弧线折角；平墙／直柱缺气囊接头与张力；白骨和台面局部高亮合并；标本四肢与躯干存在可见缝隙且物种弱；瓷器、儿童积木、化石缺材质与颜色区分；游客成年比例统一；墙图为空。接触影可见但不均匀，不能据现有一个中庭投影断言全馆最终照明通过。

下一轮复用当前原生入口和八个机位，按以下顺序执行，不复制项目或缓存：

1. **主形先行。** 同灯同镜头装入一套合格骨段／壳体样板，拍结构与玩法中庭；检查只保留轮廓和大色块时是否仍像获选A01。未通过则回到模型，不先增加表面噪声。
2. **一组材质判别。** 用现有门套、骨节、瓷器和地板对照布／硬材，近景加一个实际移动镜头；记录纹理颜色空间、法线、roughness和shader来源，不把静态高光推断成镜面能力。
3. **整场接触与状态。** 五区四连接和完整／拆落／抓取／倒塌／复位按同一相机来源取证；检查脚底、门边、裸露小件、阴影和可读性，复查变化影响的原生接口。当前通过的胶囊净空不能覆盖未来更厚的视觉外壳。
4. **实际运行测量。** 记录Godot版本、Compatibility、设备、分辨率、相机／状态、源与资产／shader哈希，并测真实运行帧时间及资源占用。当前未确定目标硬件或性能预算，不写帧率保证、面数上限或性能pass；录制时长与固定步进帧率不充当运行性能。

本计划补齐责任和验证方法；H2设计接受、H3具体生产授权及H4最终可玩样板接受仍各自依据真实结果。
