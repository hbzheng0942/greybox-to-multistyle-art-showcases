# Notices and asset provenance

This is a public collection of editable development showcases for the greybox-to-multistyle-art workflow. Publication records the current implementation and does not imply final art, animation, gameplay or performance acceptance.

Existing third-party notices are retained next to their resources. Hole includes Noto CJK under the SIL Open Font License; see `games/hole/shared/licenses/`. Godot is a separate installation and is not bundled. Generated models, textures, sound and project code retain their respective original rights; this collection does not assign a new blanket license to third-party material.

The package contains the resources needed to edit and run the selected styles, including baked scenes and editable meshes where both are used. Provider credentials, task payloads, generation services and historical rejected projects are excluded. Public manifests record package paths and SHA256 values; machine-specific provenance is retained privately by the producing team.
